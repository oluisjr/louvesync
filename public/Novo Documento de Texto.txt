Analise o projeto LouveSync e refatore completamente a arquitetura de scraping de cifras. Atualmente o scraping funciona no Playground da ScraperAPI, mas falha quando executado no app hospedado na Vercel.

# PROBLEMAS IDENTIFICADOS

1. SCRAPING SENDO FEITO NO FRONTEND

---

O arquivo scraper.js executa fetch diretamente no navegador do usuário usando proxies públicos.

Código atual:

```js
const PROXIES = [
  url => `/api/proxy?url=${encodeURIComponent(url)}`,
  url => `https://api.allorigins.win/get?url=${encodeURIComponent(url)}`,
  url => `https://corsproxy.io/?url=${encodeURIComponent(url)}`
];
```

Problemas:

* proxies públicos são facilmente bloqueados
* CifraClub detecta requests automatizadas
* Cloudflare bloqueia requisições suspeitas
* browser fetch não possui fingerprint legítima
* sem sessão persistente
* sem headers realistas
* sem bypass anti-bot

Resultado:

* HTML incompleto
* retorno 403 / 503 / 520
* challenge anti-bot
* seletor `.cifra_cnt pre` não existe

==================================================

2. DEPENDÊNCIA DE DOMParser NO CLIENTE

---

O código usa:

```js
new DOMParser()
```

Isso funciona apenas no browser.

Ao mover scraping para backend/serverless:

* DOMParser não existe no Node.js
* parser atual quebra

==================================================

3. SELETOR MUITO FRÁGIL

---

Código atual:

```js
const pre = doc.querySelector('.cifra_cnt pre');
```

Problemas:

* CifraClub muda estrutura frequentemente
* conteúdo pode vir via JS
* HTML muda dependendo do anti-bot
* alguns layouts usam `.tablatura`
* outros usam `pre.js-tab-content`

==================================================

4. ARQUITETURA ERRADA

---

Fluxo atual:

Browser
→ Proxy público
→ CifraClub

Fluxo ideal:

Browser
→ API Route da Vercel
→ ScraperAPI
→ CifraClub

==================================================

5. FALTA DE CACHE

---

Toda requisição faz scraping novamente.

Problemas:

* custo desnecessário
* mais bloqueios
* lentidão
* dependência constante do scraper

# PASSO 1 — CRIAR API ROUTE NA VERCEL

Criar:

```txt
/api/cifra.js
```

Implementar:

```js
import axios from "axios";

export default async function handler(req, res) {
  try {
    const { url } = req.query;

    const response = await axios.get(
      "http://api.scraperapi.com",
      {
        params: {
          api_key: process.env.SCRAPER_API_KEY,
          url,
          render: true,
          country_code: "br",
          premium: true
        },
        timeout: 20000
      }
    );

    res.status(200).send(response.data);

  } catch (err) {
    console.error(err);
    res.status(500).json({
      error: "Erro ao buscar cifra"
    });
  }
}
```
